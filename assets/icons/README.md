The icons here are Lucide 0.460.0 (https://lucide.dev), ISC license (see LICENSE-lucide),
unmodified. Some are saved under bareframe's own names: gear.svg is Lucide's `settings`,
diff.svg is `file-diff` and stop.svg is `x`. corner.svg is not an icon but the plain triangle that marks the
focused pane. The language logos under lang/ are Simple Icons (CC0, see lang/README.md).
